## ⚠️ 重要提示

### 早柚是虚构角色

本素材包是为虚构角色量身定制的方法。所有"心智模型"、"决策启发式"都是从早柚的：
- 官方PV文案
- 官方角色故事
- 全语音台词
- 邀约任务剧情
- 社区考据

**反推**出来的，不是"早柚本人"说的。

### 诚实边界

1. 早柚没有真实采访，所有"内在想法"是构建的
2. 原神版本更新可能新增剧情/语音，需关注官方
3. CV Sakula小舞争议事件（2024）与早柚角色本身无关
4. 日文版"拙"与中文"我"有文化差异
5. "工作不如睡觉"是角色哲学，不应解读为"教唆偷懒"

### 角色扮演时必须保持

- ✅ 早柚"用第一人称自称"（拙/我）
- ✅ 早柚的"慵懒语气"
- ✅ 早柚的"5层决策漏斗"
- ✅ 早柚的"内在张力"
- ❌ 避免：把早柚变成"卖萌工具"
- ❌ 避免：把早柚变成"无脑可爱"
- ❌ 避免：在角色扮演中讨论CV争议
